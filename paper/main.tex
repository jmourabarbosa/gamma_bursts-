\begin{abstract}
Working memory is classically attributed to persistent spiking sustained by slow NMDA receptor currents. This view has been challenged by large-scale prefrontal recordings in which the remembered item is decoded only intermittently on single trials, suggesting that memories survive silent periods through synaptic facilitation. Here we show that intermittent coding emerges from canonical attractor networks with fixed synapses and a fluctuating, attention-like global input. Brief drops in attention silence the network, but NMDA currents can bridge each silence. Fitted to monkey prefrontal recordings, a rate model reproduces the number and duration of silent states and predicts how they change with the decoded neurons. We found that silent states are more frequent in less informative samples, validating this prediction and suggesting that measured silences overestimate how often memory leaves spiking activity. Unlike synaptic facilitation, the NMDA trace also predicts memory loss when silences outlast a few hundred milliseconds. In line with this, monkeys made more errors when silent states were longer and their performance pointed to a trace of $\sim$120~ms, matching NMDA kinetics rather than the long time scale of facilitation. Finally, we replicate the main findings in a biophysical ring-attractor network of spiking neurons with NMDA-mediated recurrent excitation, demonstrating intermittent rate coding through persistent activity bridged by NMDA currents.

\end{abstract}

\section{Introduction}

Two main mechanisms have been proposed to hold information in working memory. In persistent-activity models, recurrent excitation keeps a cue-selective population firing through the delay, and slow NMDA receptor currents make this activity stable \citep{amit1997,wang1999,wang2001,compte2000}. Consistent with these models, blocking NMDA receptors markedly reduces persistent firing in monkey prefrontal cortex \citep{wangm2013}. In activity-silent models, the memory is instead stored in short-term synaptic facilitation and does not require ongoing spiking during maintenance \citep{mongillo2008,stokes2015,lundqvist2016,miller2018,panichello2024}, and hidden memories can be reactivated after periods without decodable activity \citep{rose2016,wolff2017}. Notably, the two accounts rely on traces with very different time scales. NMDA receptor currents decay on a time scale of hundreds of milliseconds \citep{vicini1998,wangh2008}, and models of persistent activity typically use an NMDA decay time constant of about 100~ms \citep{wang1999,compte2000}. On the other hand, facilitation at excitatory synapses in prefrontal cortex decays on a time scale of the order of a second \citep{thomson1997,markram1998,hempel2000,wangy2006,mongillo2008}, and activity-silent models typically use 1.5~s \citep{mongillo2008}. Synaptic augmentation, which lasts tens of seconds, has been proposed to bridge even longer silences \citep{mongillo2025}.

Rigorously testing predictions of these models requires single-trial resolution \citep{lundqvist2018}, which only recently became possible with the advance of large-scale, intracranial recordings \citep{williams2021,urai2022}. Recent studies show that working-memory information in prefrontal cortex (PFC) fluctuates within a trial \citep{panichello2024,tao2024,mozumder2026}. \citet{panichello2024} found that decoding alternates between \emph{On states} (when the memory can be read out) and \emph{Off states} (when it cannot) and concluded that synaptic changes carry the memory through \emph{Off states}. \citet{tao2024} found rare periods of 43--414~ms in which all simultaneously recorded selective neurons were silent for longer than expected by chance, and concluded that short-term plasticity is needed in a small fraction of trials. Finally, \citet{mozumder2026} found that persistent activity is asynchronous across neurons, with no population silences beyond chance. In their recordings, decoding \emph{Off states} came with reduced but not abolished tuning and were synchronized between prefrontal and parietal cortex, and the authors interpreted them as global fluctuations that exert some influence on behavior.

Here, we ask whether a single persistent-activity mechanism can account for these observations and propose that intermittent decoding does not require short-term plasticity and is in fact more consistent with the NMDA account. To illustrate this, we modelled working memory with a classic attractor model, in which two cue-selective populations sustain their firing through recurrent excitation mediated by slow NMDA currents and compete through shared inhibition \citep{wang2002,wong2006}. The synchrony of \emph{Off states} seen across prefrontal and parietal cortex \citep{mozumder2026} points to a common input as their source, and attention, which waxes and wanes on sub-second time scales \citep{fiebelkorn2019}, is a natural candidate. We therefore added to the model a fluctuating attentional input common to both populations, whose brief drops silence both populations. During each silence slow NMDA currents carry the memory across, so the cued population resumes firing when the attentional signal returns. We read out the model with the same decoding and \emph{On/Off} criteria as \citet{panichello2024} and fit how often, for how long and how deeply attention lapses to the \emph{On/Off} statistics of these recordings. The model quantitatively reproduces the number and length of \emph{On and Off states} while keeping the memory in persistent activity. Our reanalyses of the PFC recordings showed that \emph{Off states} are more frequent when fewer (or less selective) neurons are decoded, so their frequency partly reflects how well the recorded sample reads out the memory, and the attractor model predicts this dependence for decoded populations it was never fitted to. Unlike a model in which short-term facilitation carries the memory, the NMDA model predicts that errors grow with the time spent \emph{Off}, as we found in the recordings. Fitted to the monkeys' performance, the decline in accuracy with \emph{Off} time points to a trace of about 120~ms, which matches NMDA kinetics rather than facilitation. Finally, we leverage the insights from the rate model to build a ring-attractor network of spiking neurons modulated by a global signal and replicate the main results of \citet{panichello2024}. Previous work took intermittent decoding as evidence that persistent activity is not sufficient for working memory, our results show that this evidence has a more likely explanation within the standard persistent-activity account.

\section{Results}

\subsection{Input dips produce \emph{Off states} and NMDA carries the memory across them}

We started by modelling \emph{On/Off states} using a variation of the classic two-pool attractor model \citep{wang2002,wong2006}, with two memory pools, cued and uncued, that excite themselves through NMDA currents and compete through shared inhibition (Methods). The key addition to the classic model is a common input to both pools that fluctuates, which we interpret as an attentional signal, since attention is known to wax and wane on sub-second time scales (\citealp{fiebelkorn2019}; see Discussion). Without fluctuations in its input, the cued pool stays active after the cue and decoding stays \emph{On} (Fig.~1a, first second after the cue). With brief dips in this input, both pools fall silent and decoding drops to chance (Fig.~1a, after 1,000~ms). During each dip, the NMDA gating of the cued pool decays with a time constant of 150~ms and stays higher than that of the uncued pool. When the input returns, the pool with more NMDA gating wins the competition. \emph{Off states} therefore do not erase the memory, because NMDA gating carries it across each silence, and the cue is still correctly remembered at the end of the delay.

To compare the model with the data, we read it out like the recordings (Supplementary Fig.~1; Methods). In the data, a decoder trained on the recorded neurons gives every 10~ms a $z$ score of how well the cue can be read out. The model has no neurons, so we built the equivalent score from its two pools. The evidence for the cue is the difference between the cued and uncued pool rates ($\Delta r$) in the same 100~ms windows. We converted this difference into $z$ units by multiplying it by a gain $c$ and adding read-out noise $\eta$, whose variance and temporal correlations were estimated from PFC recordings using the decoder output before the cue (Methods). We confirmed the validity of this method by showing that when synthetic neurons driven by the model were decoded with the same pipeline, the decoder's z agreed with this read-out as closely as two runs of the decoder on independent datasets (Supplementary Fig.~1e–i). \emph{On and Off states} (red and cyan in Fig.~1a) are then labelled with the thresholds of \citet{panichello2024} (dashed lines in Fig.~1a). Read out this way, the model alternates between \emph{On and Off states} (Fig.~1a, bottom, mid gain). Both length distributions peak near 100~ms and have long tails (Fig.~1b), qualitatively like those in PFC recordings \citep{panichello2024}. Importantly, the \emph{On/Off} statistics depend strongly on the decoder gain. Keeping the dynamics and noise fixed for this particular simulated trial, halving the gain gave more \emph{Off states} and almost no \emph{On states}, whereas doubling it gave fewer and shorter \emph{Off states} and more \emph{On states} (Fig.~1a, bottom, low and high gain, and Fig.~1b for many trials). In the next sections, we test this prediction and ask whether the model matches the data quantitatively.

\subsection{On/Off statistics depend on which neurons are decoded}

In our reanalysis of the PFC recordings of \citet{panichello2024}, we found that \emph{On/Off} statistics depend strongly on which neurons the decoder uses, which we call the decoded population (Fig.~2, black circles). Decoders using the most cue-selective neurons spend much more of the delay \emph{On}, and less \emph{Off}, than decoders using the same numbers of randomly chosen neurons, which also show more \emph{Off states} per trial (paired Wilcoxon signed-rank tests over 25 sessions, p $<10^{-6}$ for each of 5, 20 and 50 neurons; Fig.~2). How often a memory appears \emph{Off} therefore depends partly on how well the recorded neurons read it out. This matters for interpreting \emph{Off states} as evidence for activity-silent memory. A decoder trained on a limited sample of neurons can fall to chance while the memory is still present in the activity of other, potentially unrecorded neurons. The measured fraction of time \emph{Off} is therefore an upper bound on how often the memory leaves spiking activity. We then asked if our model could explain this dependence.

To test this, we fitted the model dynamics to the decoder using all neurons in 25 sessions (Methods). The model matches the data well in \emph{Off states} per trial (3.1 vs 3.3), \emph{Off} median length (110 vs 112~ms), \emph{On states} per trial (1.9 vs 2.1) and \emph{On} median length (140 vs 134~ms) (Fig.~2, grey band). We then kept the dynamics fixed and, for each of the six other decoded populations, changed only the read-out without refitting any parameters. Its gain was calibrated on that population's decoding strength and its noise on that population's pre-cue z (Methods). The model quantitatively predicts the shift between selective and random neurons (Fig.~2; Supplementary Fig.~2).

\subsection{Errors increase with time \emph{Off}, as expected from an NMDA trace}

So far, we analysed correct trials only, but error trials can help distinguish between the two accounts of working memory. NMDA currents and short-term synaptic facilitation can both carry a memory across brief \emph{Off states}, but on very different time scales. In our model, NMDA gating decays with a time constant of 150~ms, whereas facilitation decays on a time scale of the order of a second \citep{wangy2006,mongillo2008}, comparable to the length of the whole memory period. To see explicitly what each mechanism predicts regarding error trials, we compared our model with a version in which facilitation replaces NMDA gating (STP model; Methods). Fitted in the same way, it reproduced the \emph{On/Off} statistics about as well as the NMDA model (Supplementary Fig.~3). This is expected, because in both models \emph{Off states} are driven by lapses of attention, which facilitation ($\tau$f = 1.5~s) bridges even more easily than NMDA gating ($\tau_N$ = 150~ms). We then silenced each model with a single dip in the common input of increasing duration (Methods). The NMDA model held the memory for silences of up to 350~ms and lost it for every silence from 400~ms on, because the NMDA trace had decayed too far for the cued pool to restart (about 2.5 $\tau_N$), whereas the STP model held the memory for silences as long as 1~s (Fig.~3a). The NMDA account therefore predicts that errors become more frequent when the memory stays \emph{Off} for long, whereas facilitation predicts no such relation for silences shorter than its own decay, which here spans the whole delay.

We tested this prediction by comparing \emph{On/Off} statistics between correct and error trials (Methods). Within sessions, the odds of an error increased with the total \emph{Off} time in the delay and with the mean length of \emph{Off states}, and decreased with the total \emph{On} time, but did not depend on the number of \emph{Off states} (Fig.~3b). Errors thus depended on how long the memory was \emph{Off}, not on how often it went \emph{Off}. Frequent \emph{Off states} are harmless as long as each is brief. Across all 25 sessions, total \emph{Off} time increased the odds of an error ($\beta$ = 0.32, 95\% CI 0.20--0.43, $p =$ 1$\times10^{-5}$; logistic mixed model with sessions as random effects, Methods). The effect was clear in monkeys H and J ($\beta$ = 0.48, $p =$ 1$\times10^{-4}$, and $\beta$ = 0.52, $p =$ 0.005) and weaker in monkey A ($\beta$ = 0.10, $p =$ 0.13).

Finally, we asked which time constant of the trace best explains how performance falls with \emph{Off} time. We varied $\tau_N$ in the fitted NMDA model, keeping the dip statistics and all other parameters unchanged, and simulated each version with the same random dips, read out as the data. We linked the probability that the memory was held to the probability of a correct response, assuming that the monkeys guess among the 8 locations after a memory loss (Methods). With the best-fitting $\tau_N$ of 123~ms, the model reproduced the decline of the pooled fraction correct (Fig.~3c). Resampling sessions gave a 95\% confidence interval of 101--190~ms (Fig.~3d). The decline of performance with \emph{Off} time thus calls for a trace of about 120~ms, close to measured NMDA receptor kinetics and to the 150~ms assumed in the fitted model, and far shorter than the time scale of facilitation.

\subsection{Intermittent rate coding in a biophysical ring-attractor network without short-term plasticity}

The rate model describes the activity of two populations, with one discrete attractor for each memory. It leaves open whether its mechanism works in a continuous attractor, which can hold any location and along which the memory could drift during silences, and in a network of spiking neurons, where NMDA currents, recurrent inhibition and noise interact at the level of single cells. We therefore turned to the spiking network of \citet{compte2000}, a ring of 2,048 excitatory and 512 inhibitory integrate-and-fire neurons in which recurrent excitation is mediated by NMDA receptors and a localized bump of persistent activity holds the cued location. We used this network with minimal changes (Methods). The NMDA decay time was set to 150~ms, as in the rate model, the neurons were made heterogeneous, and all excitatory neurons received the same kind of fluctuating attentional input as the rate model. The network was not fitted to the data. We sampled 330 of its neurons, the average number of units recorded per session, and read them out with the same decoder, null and \emph{On/Off} labelling as the recordings.

With a constant attentional input, the cued location was held by a stable bump of persistent activity, and decoding stayed \emph{On} throughout the delay (Fig.~4a, first second after the cue). Each drop of the input silenced the bump, and decoding fell to chance. When the input returned, the bump restarted at the cued location, because the cued neurons kept more NMDA gating through the silence than the other neurons, as in the rate model. Read out like the recordings, the network therefore alternated between \emph{On and Off states} (Fig.~4a, bottom). As in the recordings and the rate model (Figs. 1b and 2), \emph{On/Off} statistics depended on which neurons were decoded. Decoders using the 20 most cue-selective neurons gave \emph{On and Off states} of similar lengths to decoders using all units, but fewer of them (Fig.~4b). \emph{On} about a third of trials, the decoder using the 20 most cue-selective neurons stayed \emph{Off} for the whole delay, because these neurons all preferred the same cue of the decoded pair and were silent on trials of the other cue.

Finally, \citet{panichello2024} found that neurons lose their memory tuning during \emph{Off states} and concluded that synaptic changes carry the memory through these periods. We applied their cross-validated analysis to the spiking network. Held-out neurons were strongly tuned to the cued location during \emph{On states} and barely tuned during \emph{Off states} (Fig.~4c), as in the recordings. In the plane of the eight cue-condition means, delay activity of both the network and the recordings moved toward the centre during \emph{Off states} (Fig.~4d), and its alignment with the cued location dropped but remained above its level before the cue (Fig.~4e). Even when the decoder labelled the memory \emph{Off}, population activity therefore still held a weak code for the cued location. \emph{Off states} defined by a decoder thus overestimate how often the memory leaves spiking activity, as the dependence of \emph{On/Off} statistics on the decoded population also suggests (Fig.~2). Together, these results show that intermittent rate coding, including the loss of tuning in \emph{Off states}, emerges in a biophysical attractor network without short-term plasticity.

\section{Discussion}

Recent large-scale recordings found that prefrontal decoding of a remembered item is intermittent on single trials \citep{panichello2024,tao2024,mozumder2026}, suggesting that memories survive silent periods through synaptic facilitation \citep{mongillo2008,stokes2015,lundqvist2016,miller2018,panichello2024}. We showed that the same \emph{On/Off} statistics arise in conventional attractor models with fixed synapses. In the models, \emph{Off states} occur when a common input briefly drops, and the memory survives each silence because NMDA receptor currents decay slowly enough to bias which pool restarts. Fitted to the decoder trained on the empirical data, the rate model reproduced the number and length of \emph{On and Off states} while keeping the memory in persistent activity. Unlike a model in which short-term facilitation carries the memory, it also predicted that errors grow with the time spent \emph{Off}, which we validated in prefrontal recordings.

In the recordings, \emph{Off states} were more frequent and \emph{On states} rarer when the decoder used random rather than selective neurons. This showed that a decoder falls to chance whenever the memory signal in its sample is weak relative to its noise, not only when the memory is absent from the network. The fraction of time \emph{Off} measured from a limited sample is therefore an upper bound on how often the memory leaves spiking activity, and comparisons of \emph{Off-state} statistics across studies or brain areas need to take the decoded population into account. The model captured this shift without refitting by changing only the read-out gain and noise, both calibrated from the data.

Our account is consistent with the other recent recordings of \emph{Off states}. \citet{mozumder2026} found that \emph{Off states} were synchronized between prefrontal and posterior parietal cortex, came with lower firing rates, and showed no obvious rhythmicity. A common input that reaches several areas and fluctuates irregularly, as in our fit, would produce such coordinated, aperiodic \emph{Off states}. \citet{tao2024} likewise found that information is reduced but present between gamma bursts. Our model is compatible with both, because NMDA currents can carry the memory across full silences but are not needed when activity is only reduced. While attention is sustained, the memory is held by persistent activity without any \emph{Off state} (Fig.~1a, first second after the cue).

We interpreted the common input as an attentional signal that is high when attention is deployed on the memorandum and drops during lapses. Two lines of evidence support this interpretation. First, \citet{engel2016} found that spiking in macaque area V4 alternates between \emph{On and Off} episodes that occur synchronously across cortical layers. Importantly, these states were identified directly from population spiking, not from a decoder. \emph{Off} episodes lasted about 100~ms on average (102~ms during stimulus-driven and 118~ms during spontaneous activity), close to the \emph{Off states} in prefrontal decoding (about 110~ms) and within the time an NMDA trace can bridge. Spatial attention lengthened \emph{On} episodes and made transitions less frequent, and monkeys detected a stimulus change more often when it occurred during an \emph{On} episode than during an \emph{Off} episode. Second, sustained attention samples the environment rhythmically rather than continuously. In humans, detection of threshold stimuli depends on the phase of ongoing EEG oscillations near 7~Hz \citep{busch2009}, especially at attended locations \citep{busch2010}, and when attention is divided between two locations, detection at each fluctuates at about 4~Hz \citep{landau2012}. Similarly in monkeys, frontal eye field and lateral intraparietal activity alternates at theta frequencies (3--8~Hz) between periods of enhanced perception and periods in which attention is more likely to shift \citep{fiebelkorn2018}, and human intracranial recordings show similar theta-rhythmic sampling in frontoparietal cortex \citep{helfrich2018}. Because attention and working memory share prefrontal mechanisms \citep{awh2001,panichello2021}, lapses of attention could plausibly reach the memory network. In the fitted model, the attention signal recovers about five times per second, or one cycle every $\sim$200~ms. This is in the low theta range reported for attentional sampling \citep{landau2012,fiebelkorn2018,helfrich2018}. Importantly, in contrast with these previous studies, the fitted signal was not periodic.

In our models, the memory is carried across each silence by NMDA gating that decays with a time constant of 150~ms and reflects recent firing rather than plasticity. This lies within the range of NMDA receptor currents, which decay over hundreds of milliseconds \citep{vicini1998,wangh2008} and are required for persistent firing in primate prefrontal cortex \citep{wangm2013}. \emph{Off states} last about 100~ms, within the time an NMDA trace can bridge, so no longer-lasting mechanism is needed to explain them. The matching between behavioural simulations and data points also supports this interpretation. A memory held by facilitation decaying on a time scale of the order of a second should hardly be affected by a few hundred more milliseconds \emph{Off}, as the STP model showed. We found that errors increased with the time spent \emph{Off} and with the length of \emph{Off states}, but not with their number (Fig.~3). This is expected from a trace that bridges brief silences but not long ones. Fitted to the monkeys' performance, the time constant of this trace was about 120~ms (95\% CI 101--190~ms), close to measured NMDA receptor kinetics and far shorter than that of facilitation. Activity-silent mechanisms may still matter on longer time scales, for example to carry information between trials, when prefrontal memory traces are reactivated before the next stimulus \citep{barbosa2020}. Notably, this between-trial trace is not a voluntary memory. It does not require attention and shows up as involuntary serial biases in behaviour, rather than as the information the subject actively maintains \citep{kiyonaga2017,pascucci2023}. Persistent activity and slower silent traces are therefore not mutually exclusive.

In sum, intermittent decoding of working memory is expected from an attractor network with slow NMDA currents and a fluctuating, attention-like input. Its statistics depend on how well the recorded neurons read out the memory, and errors increase with the time spent \emph{Off}, as expected from the limited duration of the NMDA trace. These results reconcile intermittent rate coding with persistent-activity accounts, identify a trace of about 120~ms that bridges \emph{Off states}, and link \emph{Off states} to the rhythmic but irregular nature of attentional sampling.

\section{Methods}

\subsection{NMDA rate model}

The model is the reduced two-pool attractor model of \citet{wong2006}, with the changes described below.
Two excitatory memory pools, $i \in \{\cued, \uncued\}$, have rates $r_i$ and NMDA gating $s_i$.
They share an inhibitory population $r_I$ and receive a feed-forward inhibition $q$ that follows the common input $m(t)$ with a lag.
Parameters in bold were free during fitting; all others were fixed.
\begin{align}
  \tau_r \frac{dr_i}{dt} &= -r_i + \varphi(x_i), \\
  x_i &= \bm{w_s} s_i + w_a r_i - w_I r_I + I_0\, m(t) - w_{\mathit{ff}}\, q + \mathrm{cue}_i + \bm{\sigma} \xi_i, \\
  \tau_N \frac{ds_i}{dt} &= -s_i + \beta\, r_i (1 - s_i), \\
  \tau_I \frac{dr_I}{dt} &= -r_I + w_{EI} \left(r_\cued + r_\uncued\right), \\
  \tau_{\mathit{ff}} \frac{dq}{dt} &= -q + m(t).
\end{align}
The transfer function $\varphi$ is a logistic sigmoid, $\varphi(x) = r_{\max} / \bigl(1 + \exp(-(x - 1)/\kappa)\bigr)$, with maximum rate $r_{\max}$, threshold 1 and slope $\kappa$, and $\xi_i$ are independent Ornstein--Uhlenbeck noises ($\tau_\xi = 10$~ms).
Fixed parameters: $r_{\max} = 150$, $\kappa = 0.06$, $w_a = 0.0141$, $\beta = 0.02$, $w_I = 0.04$, $w_{EI} = 0.5$, $w_{\mathit{ff}} = 0.8$, $I_0 = 1.496$; $\tau_r = 10$~ms, $\tau_I = 1$~ms, $\tau_{\mathit{ff}} = 15$~ms, $\tau_N = 150$~ms.
The implementation differs from \citet{wong2006} in three respects: the transfer function is a saturating sigmoid, competition between the pools goes through an explicit inhibitory population, and a lagging feed-forward inhibition is added.
Parameter values could therefore not be taken directly from their study.
We chose them by hand so that each pool is bistable, with a low state near 0~Hz and a high state of about 85~Hz, and so that shared inhibition allows only one pool to be active at a time.
The cue is a 50~ms input of amplitude 1 to the cued pool, after 300~ms of baseline, followed by a 1,600~ms delay.
Equations were integrated with Euler steps of 0.1~ms.
The memory was scored correct when, in the last 100~ms, the NMDA gating of the cued pool exceeded the uncued pool's by more than 0.05.
We scored NMDA gating rather than rates because the model may be silent at the end of the delay, and a strong attentional input, modelling the response period, restarts the pool with more NMDA gating and so recovers the correct response (not shown).

Our main modification to this model is the common input $m(t)$ to both pools, which represents fluctuating attention.
It is 1 except during dips, where it drops to $1 - \bm{\delta}$ with 10~ms ramps.
Dip lengths are gamma-distributed (mean $\bm{\mu_d}$, shape $\bm{k}$), and the gaps between dips are exponential with mean $1/\bm{\lambda_d}$.

\subsection{STP model}

To compare our model with a short-term plasticity account, we replaced the NMDA gating $s_i$ in the recurrent input by a saturating synaptic activation without a time constant of its own, $S_i = g_i/(1 + g_i)$, with $g_i = \beta r_i u_i/U$, where $u_i$ is Tsodyks--Markram short-term facilitation \citep{mongillo2008,mi2017}:
\begin{equation*}
  \tau_f \frac{du_i}{dt} = U - u_i + \tau_f U (1 - u_i) r_i,
\end{equation*}
with $U = 0.3$ and $\tau_f = 1.5$~s. To simplify fitting and to give the STP model the best chance to fit the data, synaptic depression was switched off: with depression ($\tau_d = 0.3$~s), each re-ignition ended too early and \emph{On states} were too short (112 vs 172~ms in the data). All other parameters were as in the NMDA model, and the STP model was fitted in the same way to the decoder using all neurons, with an additional penalty for population spikes before the cue. Best fit: $\bm{w_s} = 0.69$, $\bm{\lambda_d} = 5.5$/s, $\bm{\mu_d} = 212$~ms, $\bm{k} = 0.70$, $\bm{\delta} = 0.39$, $\bm{\sigma} = 0.005$. Both models matched the \emph{On/Off} statistics about equally well (loss 9.7 for the NMDA model and 10.4 for the STP model, on 2,112 trials) and held the memory in nearly all trials.

\subsection{Spiking network}

We used the spatial working-memory network of \citet{compte2000} with minimal changes. It consists of 2,048 pyramidal neurons and 512 interneurons, modelled as leaky integrate-and-fire neurons and arranged on a ring by preferred location. Recurrent excitation is mediated by NMDA receptors with a voltage-dependent Mg$^{2+}$ block and saturating gating. Connections between pyramidal neurons decrease with the difference in their preferred locations (Gaussian footprint, $\sigma = 18^\circ$), and all connections involving interneurons are uniform. All neurons receive external excitatory Poisson input through AMPA receptors. Neuronal and synaptic parameters were those of \citet{compte2000}, with four changes. First, the NMDA decay time was 150~ms instead of 100~ms, as in the rate model, and the NMDA conductance between pyramidal neurons was lowered from 0.381 to 0.33~nS so that the network remained bistable with the slower decay. Second, we made the neurons heterogeneous, so that their activity would resemble recorded neurons more closely. Firing thresholds varied across neurons (SD 0.3~mV), and each pyramidal neuron received a random fraction of its recurrent excitation through a broad, weakly tuned footprint instead of the narrow one. To keep the bump stable despite this weaker tuned input, the peak of the narrow footprint was raised from 1.62 to 3.0. Third, the cue was a 50~ms current to the pyramidal neurons around the cued location, as long as in the task and stronger than in \citet{compte2000} (500~pA), so that it reliably started a bump. Fourth, as in the rate model, the external input to all pyramidal neurons was scaled by a common attentional signal $m(t)$ that dropped at random times and briefly overshot when it recovered. Equations were integrated with Euler steps of 0.1~ms.

As in \citet{compte2000}, the membrane potential $V$ of each neuron obeys
\begin{equation*}
C_m \frac{dV}{dt} = -g_L (V - E_L) - I_\mathrm{ext} - I_\mathrm{NMDA} - I_\mathrm{GABA} + I_\mathrm{cue},
\end{equation*}
with $C_m = 0.5$~nF and $g_L = 25$~nS for pyramidal neurons, $C_m = 0.2$~nF and $g_L = 20$~nS for interneurons, $E_L = -70$~mV, a firing threshold of $-50$~mV, a reset potential of $-60$~mV and refractory periods of 2~ms (pyramidal neurons) and 1~ms (interneurons). The synaptic currents are
\begin{align*}
I_\mathrm{ext} &= g_\mathrm{ext}\, s_\mathrm{AMPA} (V - E_E), \\
I_\mathrm{NMDA} &= g_\mathrm{NMDA}\, B(V) (V - E_E) \textstyle\sum_j W_{ij}\, s_{\mathrm{NMDA},j}, \\
I_\mathrm{GABA} &= g_\mathrm{GABA} (V - E_I) \textstyle\sum_j s_{\mathrm{GABA},j},
\end{align*}
with $E_E = 0$~mV, $E_I = -70$~mV and $B(V) = 1/(1 + [\mathrm{Mg}^{2+}] \exp(-0.062\,V)/3.57)$, $[\mathrm{Mg}^{2+}] = 1$~mM. The AMPA and GABA$_\mathrm{A}$ gating variables increase by 1 at each presynaptic spike and decay with $\tau_\mathrm{AMPA} = 2$~ms and $\tau_\mathrm{GABA} = 10$~ms. The NMDA gating of each pyramidal neuron obeys
\begin{equation*}
\frac{dx}{dt} = -\frac{x}{\tau_x} + \sum_k \delta(t - t_k), \qquad \frac{ds_\mathrm{NMDA}}{dt} = -\frac{s_\mathrm{NMDA}}{\tau_\mathrm{NMDA}} + \alpha\, x (1 - s_\mathrm{NMDA}),
\end{equation*}
with $\tau_x = 2$~ms, $\alpha = 0.5$~ms$^{-1}$ and $\tau_\mathrm{NMDA} = 150$~ms. External Poisson input arrives at 1.8~kHz, with $g_\mathrm{ext} = 3.1$~nS onto pyramidal neurons and 2.38~nS onto interneurons. Recurrent conductances are $g_\mathrm{NMDA} = 0.33$~nS between pyramidal neurons and 0.292~nS from pyramidal neurons to interneurons, and $g_\mathrm{GABA} = 1.336$~nS onto pyramidal neurons and 1.024~nS onto interneurons. Between pyramidal neurons with preferred locations $\theta_i$ and $\theta_j$,
\begin{equation*}
W_{ij} = J^- + (J^+ - J^-) \exp\!\left(-\frac{(\theta_i - \theta_j)^2}{2\sigma^2}\right),
\end{equation*}
normalised to a mean of 1, with $\sigma = 18^\circ$ and $J^+ = 3.0$. For heterogeneous tuning, pyramidal neuron $i$ received a fraction $h_i$ of this input ($h_i$ uniform between 0 and 1) through $1 + 0.25 \cos(\theta_i - \theta_j)$ instead of $W_{ij}$. The external input rate to pyramidal neurons was multiplied by $m_\mathrm{eff}(t) = m(t) + A\,[m(t) - \bar m(t)]$, where $m(t)$ is the attentional signal, $\bar m(t)$ follows $m(t)$ down into each dip and recovers with a time constant of 150~ms, and $A = 1$.

The dip statistics of the spiking network were set by hand rather than fitted, but differ only slightly from those of the fitted rate model. Dips started at random times (Poisson, 7 per s instead of 10.2 per s), lasted longer (gamma distribution with the same shape, mean 150~ms instead of 90~ms) and were shallower (50\% instead of 60\% of the drive), with 10~ms ramps as in the rate model. The spiking network needed longer dips because its decoding was stronger. With 90~ms dips, the 100~ms decoding windows bridged most silences and \emph{Off states} were rare. In both models, the drive briefly overshoots when the input recovers. In the rate model, this overshoot comes from the lagging feed-forward inhibition ($\tau_{\mathit{ff}} = 15$~ms). In the spiking network, a fast overshoot made all pyramidal neurons fire together, which saturated their NMDA gating and erased the memory, so the overshoot decayed with a time constant of 150~ms.

Sessions of 480 trials (60 per cue location, 8 locations) were simulated, each with 500~ms of fixation, a 50~ms cue and a 1,500~ms delay with dips throughout. In each session, 330 neurons (264 pyramidal neurons and 66 interneurons) were sampled at random across the ring and read out exactly as the recordings, with the same windows, decoder, label-shuffle null and \emph{On}/\emph{Off} labelling (4 sessions, Fig.~4b), using all units or the 20 most cue-selective neurons (ranked by split-half ANOVA between the two cues of each decoded pair). Memory tuning in \emph{On} and \emph{Off states} was computed as in \citet{panichello2024}. Firing rates in 100~ms windows were $z$-scored across trials, the recorded neurons were split at random into two halves, and \emph{On} and \emph{Off states} were labelled with the decoder of one half. The delay tuning of each held-out neuron was computed separately for \emph{On} and \emph{Off} time points and aligned to its preferred cue, and the same analysis with shuffled cue labels was subtracted to remove the bias of this alignment (10 random splits, 330 neurons of one session).

Delay activity during \emph{On} and \emph{Off states} (Fig.~4d, e) was analysed in the same way in the recordings and in the network. In each session, neurons were split at random into two halves. \emph{On} and \emph{Off states} were labelled from one half, with the decoder and criteria above, and all other analyses used the other half. In the recordings, states were labelled from the 20 most cue-selective units of the labelling half. In the network, they were labelled from all of its neurons, because its 20 most selective neurons often preferred the same cue and were silent on trials of the other cue while the bump was still active. Delay activity ($z$-scored firing rates in 100~ms windows, 500--1,400~ms after cue onset) was averaged for each of the eight cue locations, and PCA was applied to these condition means. Axes were estimated on one half of the trials, used to project the other half, and aligned across halves by an orthogonal Procrustes rotation. Each trial's position was averaged over its \emph{On} and, separately, its \emph{Off} time points. Its alignment was the cosine between this position and the direction of its cue's mean in the other half of the trials, minus the same quantity with cue labels shuffled within each half (50 shuffles). Activity before the cue, projected on the same axes, served as a null (window centres from $-400$~ms to cue onset in the recordings and to $-50$~ms in the network, whose neurons respond to the cue within a few milliseconds). Ten simulated sessions were analysed.

\subsection{Data}

We reanalysed the recordings of \citet{panichello2024}: 25 sessions, correct trials only (error trials were used only in the behavioural analysis), all cue locations (13,190 trials; 329 units per session on average).
For each time bin, an L2-regularised logistic decoder ($\lambda = 10{,}000$) was evaluated with approximate leave-one-out and $z$-scored against 30 shuffled label sets per cue pair.
Decoded populations were all neurons, the $k$ most cue-selective neurons (ranked by split-half ANOVA), and $k$ randomly chosen neurons (10 draws, averaged within sessions), with $k = 5$, 20 and 50.
Decoded populations of the same size were compared within sessions with two-sided Wilcoxon signed-rank tests on the session values (random draws averaged within each session).

\subsection{Behavioural analysis}

To relate \emph{On/Off states} to behaviour, we also labelled error trials (15,468 trials in total, 2,278 errors). Error trials were decoded with decoders fitted on all correct trials of the same cue pair, so they were also out of sample, and their rates were z-scored with the mean and SD of correct trials. For each trial, we computed the total \emph{Off} time and the total \emph{On} time in the delay (500--1,400~ms after cue onset), the number of \emph{Off states} and their mean length (13,962 trials with at least one \emph{Off state}). For each statistic, the probability of an error was modelled with a logistic mixed model, error ${\sim}$ z(stat) + t + t² + monkey + (1 + z(stat) || session), where z(stat) is the statistic z-scored within each session, so that only within-session variation is used, t is the time within the session, and each session has a random intercept and an uncorrelated random slope. Monkey was a fixed effect, as three monkeys are too few to estimate a random effect. Models were fitted with the Laplace approximation and tested with likelihood-ratio tests against the same model without the statistic. For the fit of $\tau_N$, trials were pooled over sessions and binned by \emph{Off} time in 90~ms bins (one tenth of the delay window).

\subsection{Decoding read-out, \emph{On/Off} labelling and statistics}

To compare the model with the recordings, we measured \emph{On} and \emph{Off states} as close as possible to how they were measured in the data \citep{panichello2024}, where they are defined on the $z$ score of a decoder trained on the neurons recorded in a session. The model does not generate the activity of individual neurons. Instead, it describes the latent dynamics of a working-memory circuit, from which some neurons were recorded. Labelling \emph{On/Off states} from the pool rates of the model directly would ignore the read-out noise inherent to recording only a small sample of the neurons in the circuit. We therefore converted the model's activity into a decoding $z$ score with the same time resolution, noise and labelling as the data (Supplementary Fig.~1).

At each time step, the decoding evidence was the difference between the cued and uncued pool rates, $\Delta r(t)$. $\Delta r$ is large when the cued pool is active and near zero when both pools are silent, and it was averaged in 100~ms windows stepped by 10~ms, as in \citet{panichello2024}. We modelled the $z$ score as $z(t) = c\,\Delta r(t) + \eta(t)$, where the gain $c$ converts rates into $z$ units and $\eta$ is the read-out noise, the variability of a decoder trained on a finite number of neurons and trials (Supplementary Fig.~1a).

The noise $\eta$ dynamics was estimated from the data before the cue, where the decoder $z$ carries no memory signal and therefore reflects read-out noise alone. The standard deviation of pre-cue $z$, averaged over the 25 sessions, was 1.06 for each decoded population, close to the value of 1 expected for a $z$ score, so we gave $\eta$ unit variance. In \citet{panichello2024}, $z$ was computed in 100~ms windows stepped by 10~ms, so consecutive points share most of their spikes and the noise at two points $\Delta t$ apart is correlated. We generated this part of $\eta$ as white noise averaged in the same overlapping windows, $\varepsilon(t) = \frac{1}{\sqrt{10}}\sum_{j=0}^{9} w(t - 10j~\mathrm{ms})$, where $w$ are independent standard normal values drawn every 10~ms. In the data, $z$ remained correlated beyond window size (100~ms, Supplementary Fig.~1b), possibly because the decoder output also drifts slowly from trial to trial. In the model, we captured this drift by adding to each trial a constant offset $\xi$, drawn independently for each trial from a standard normal distribution. The weight of this offset was set by $\rho$, the share of the noise variance that is constant within a trial, which we measured in the data as the correlation of pre-cue $z$ between time points 200~ms apart. These points are far enough apart that their windows do not overlap, so their correlation can only come from the per-trial drift ($\rho$ = 0.35 for all neurons, 0.09 for the most selective neurons and 0.11 for random neurons). Thus $\eta(t) = \sqrt{1-\rho}\,\varepsilon(t) + \sqrt{\rho}\,\xi$, where $\varepsilon$ is the window-averaged white noise. Both $\varepsilon$ and $\xi$ have unit variance, so $\eta$ does too, and its autocorrelation is $(1-\rho)(1-\Delta t/100~\mathrm{ms}) + \rho$ for $\Delta t < 100$~ms and $\rho$ beyond, as in the data (Supplementary Fig.~1b).

We also calibrated the gain c on a separate property of the data, the level that $z$ reaches when the memory is read out, which we call the decoding strength. The mean of the delay $z$ would not serve this purpose, because the delay $z$ mixes time points with strong and weak decoding (e.g. \emph{On} vs \emph{Off}). We therefore fitted a two-component Gaussian mixture to the delay $z$ values (500--1,400~ms after cue onset) and took the mean of the upper component, which reflects the level of $z$ during strong decoding (\emph{On}) and depends much less on how often $z$ is low (\emph{Off}). For each decoded population, $c$ was set so that the decoding strength of the model's delay $z$ equaled the data's, averaged over sessions (Supplementary Fig.~1c,d).

States were labelled exactly as in \citet{panichello2024}, so that model and data are compared with identical definitions. \emph{On states} are runs of $z > 1.96$ whose summed $z$ exceeds the 95th percentile of the same quantity in pure noise $\eta$. \emph{Off states} are runs of at least 5 points (50~ms) with $z < 0.84$. States were counted from 0 to 1,400~ms after cue onset, and fractions of the delay spent \emph{On} or \emph{Off} from 500 to 1,400~ms. Model statistics were computed from 2,112 simulated trials (Fig.~2). Data statistics are means over the 25 sessions; for random neurons, the 10 draws were first averaged within each session (Fig.~2).

Our read-out approximates a real decoder by a simple formula ($z(t) = c\,\Delta r(t) + \eta(t)$), so we tested whether the calibration recovers the gain and the \emph{On/Off} statistics of a real decoder in synthetic data where the ground truth is known (Supplementary Fig.~1e--i). We used the fitted model to generate spikes and decoded them with the same data pipeline. The model was simulated for two cue locations, A and B. When A was cued, pool A was the cued pool and pool B the uncued one, and the reverse when B was cued, which gives the decoder two classes to discriminate, as in the data. The pool rates drove 330 Poisson neurons, the average number of units recorded per session (329). 30\% of them followed pool A or pool B (half each) and the rest were untuned. Baseline rates were lognormal with a median of 5~Hz, and all neurons shared a per-trial gain, which produces slow trial-to-trial drift as in the data. We simulated 70 trials per cue location, close to the number of correct trials per location in a session, and 8 synthetic sessions at each of three tuning strengths, chosen so that the decoder's decoding strength matched that of the data's random-20, all-unit and top-20 decoders (Supplementary Fig.~1f). The fraction of tuned neurons matters only through this decoding strength, which the tuning strength sets. We then applied to the synthetic decoder output exactly the calibration used for the data. The recovered gain c grew in proportion to the tuning strength of the synthetic neurons, and its values (0.030, 0.050 and 0.086) were close to the gains of the model calibrated on the corresponding data decoders (0.029, 0.051 and 0.088; Supplementary Fig.~1g). With this gain and with $\rho$ estimated from the pre-cue autocorrelation, the read-out $z$ correlated with the decoder's as closely as two runs of the decoder on independent spikes from the same rates (Supplementary Fig.~1h). It reproduced the number and fraction of \emph{Off states}, and undercounted \emph{On states} by about one per trial (Supplementary Fig.~1i).

\subsection{Fitting}

Six parameters were fitted with the covariance matrix adaptation evolution strategy \citep{hansen2001} to the decoder using all neurons: $\bm{w_s}$, $\bm{\lambda_d}$, $\bm{\mu_d}$, $\bm{k}$, $\bm{\delta}$ and $\bm{\sigma}$.
The NMDA decay time was not fitted but fixed at $\tau_N = 150$~ms, within the range measured in cortex \citep{vicini1998,wangh2008,wangm2013}.
The loss combined the squared scaled errors of six statistics (\emph{On and Off states} per trial, mean lengths and fractions of the delay), the squared Hellinger distance between model and data length distributions (states $\geq 40$~ms), and a penalty when the memory was correct in fewer than 98\% of trials.
Best fit: $\bm{w_s} = 1.30$, $\bm{\lambda_d} = 10.2$/s, $\bm{\mu_d} = 90$~ms, $\bm{k} = 8.7$, $\bm{\delta} = 0.60$, $\bm{\sigma} = 0.006$.

\subsection{Simulations of memory against \emph{Off} time}

To compare with the behaviour, each fitted model was then simulated with random dips drawn from its fitted dip statistics (100,000 trials per model); the memory was held in 98.5\% (NMDA model) and 99.99\% (STP model) of these trials. To measure how long each model can hold the memory through a single silence (single-dip test, Fig.~3a), we simulated trials with only one dip of the common input, starting 500~ms after cue onset, with the model's fitted depth and a length from 0 to 1,000~ms in 25~ms steps (300 trials per length, 12,300 trials per model). Fig.~3a shows the fraction of these trials with the memory held against dip duration. Trials were read out with the all-units gain and noise of the fitted model, and the memory was scored as in the NMDA model, using the facilitation $u_i$ instead of the NMDA gating in the STP model. \emph{Off} time was computed as in the data.

\subsection{NMDA time constant fitted to performance}

The fitted NMDA model, with random dips drawn from the fitted dip statistics (the same dips for every $\tau_N$) and the all-units read-out, was simulated with $\tau_N$ from 20 to 1,500~ms (17 values, 30,000 trials each) and all other parameters unchanged, so the \emph{On/Off} statistics drift away from their fitted values as $\tau_N$ changes. For each $\tau_N$, the probability that the memory was held was computed in the ten \emph{Off}-time bins and interpolated in log $\tau_N$. The model was linked to behaviour by P(correct) = $p_0$ $\times$ [P(held) + G $\times$ P(lost)], where G = 1/8 is the chance of a correct guess among the 8 cue locations after the memory is lost, and $p_0$ is the performance when the memory is held, which absorbs errors that do not depend on \emph{Off} time. $\tau_N$ and $p_0$ were fitted by maximum likelihood to all 15,468 trials pooled (best $p_0$ = 0.887). Confidence intervals came from 1,000 bootstraps over sessions (25 sessions drawn with replacement, their trials pooled and refitted). The estimate depended little on G: the best $\tau_N$ was 129, 118 and 102~ms for G = 0, 1/4 and 1/2.
